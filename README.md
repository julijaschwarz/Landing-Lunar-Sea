# Landing Lunar Sea

[![Lint](https://github.com/julijaschwarz/Landing-Lunar-Sea/actions/workflows/lint.yml/badge.svg)](https://github.com/julijaschwarz/Landing-Lunar-Sea/actions/workflows/lint.yml)

This is the first project by profession as a typesetter on Hexlet.io

The result of this project is the landing of the Lunar Sea residential complex.

The project can be found on the website [https://julijaschwarz.github.io/Landing-Lunar-Sea/](https://julijaschwarz.github.io/Landing-Lunar-Sea/).

## Development

The page itself is plain static HTML and CSS — open `index.html` in a browser, no build step required. The npm packages are linters only.

```bash
npm ci        # install the linters
npm run lint  # check CSS with stylelint and HTML with htmlhint
```
